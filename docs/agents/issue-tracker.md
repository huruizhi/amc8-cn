# Issue tracker

## Location

GitHub Issues in `huruizhi/amc8-cn`.

## Workflow

- Use `gh issue list`, `gh issue view`, and `gh issue create` for issue work.
- Keep feature specifications and implementation tickets in GitHub Issues.
- Apply the `ready-for-agent` label to implementation-ready tickets.
- The local checkout is the source of truth for code and the GitHub repository is the source of truth for tracked work.

## Authentication

The configured `gh` account must be authenticated before publishing issues. If `gh auth status` reports an invalid token, stop before attempting to create or edit issues.
