# 章节页面完成状态与前置提醒

## Parent

https://github.com/huruizhi/amc8-cn/issues/1

## What to build

在章节详情页展示基础练习与学完检查的提交进度、正确率和掌握状态，并保留前置章节提醒。前置章节未完成时仍允许访问当前章节。

## Acceptance criteria

- [ ] 页面展示已提交题数、总题数和当前正确率。
- [ ] 未完成全部题目时，完成按钮保持不可用。
- [ ] 全部提交且正确率达到 80% 时，可以标记章节完成。
- [ ] 前置章节以可点击链接显示，不阻塞当前章节访问。
- [ ] 刷新页面后，已有本地进度仍然可见。

## Blocked by

- 章节掌握评估器
- 第 1–5 章原创学完检查
