# 第 1–5 章原创学完检查

## Parent

https://github.com/huruizhi/amc8-cn/issues/1

## What to build

为算术的性质、指数、数论、分数、方程与不等式各增加 3 道原创综合检查题，并接入章节内容，使学生完成基础练习后能检查知识迁移能力。

## Acceptance criteria

- [ ] 第 1–5 章每章恰好有 3 道学完检查题。
- [ ] 每道题有 A–D 四个选项、唯一答案和中文解析。
- [ ] 每章检查题覆盖基础理解、方法迁移和综合应用中的至少两类。
- [ ] 题目不复制 AoPS 原书内容，难度与对应章节一致。
- [ ] 检查题结果进入统一掌握评估。

## Blocked by

- 章节掌握评估器
