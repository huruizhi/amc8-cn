# 章节掌握评估器

## Parent

https://github.com/huruizhi/amc8-cn/issues/1

## What to build

为学习章节提供统一的掌握评估：根据章节练习和学完检查的提交结果，计算已提交题数、答对题数、总题数、正确率和是否达到完成标准。

## Acceptance criteria

- [ ] 全部题目未提交时，评估结果显示未完成。
- [ ] 只提交部分题目时，评估结果显示未完成。
- [ ] 全部提交且正确率低于 80% 时，评估结果显示未达标。
- [ ] 全部提交且正确率达到 80% 时，评估结果显示达标。
- [ ] 结果可被章节页面复用，不依赖浏览器或 React 状态。

## Blocked by

- None (can start immediately)
