# AMC 8 中文练习站

一个面向中文学习者的 AMC 8 双语学习站。当前收录 2018–2020、2022–2026 八个年度，共 200 道题，并提供四年级自学学习路径。

## 功能

- 中英文题面、选项与解析
- 按知识点组织的学习路径
- 每课包含知识目标、例题分步讲解、基础练习和对应真题
- 学习章节完成进度与真题进度分开记录
- 按年份连续练习
- 按难度、主题、能力和题型组合筛选
- 提交答案后才能查看正确答案与解析
- 错题、重做与掌握度分析
- 学习进度保存在当前浏览器
- 学习记录 JSON 导入与导出
- 匿名题目问题报告
- 移动端与桌面端响应式界面

## 本地运行

需要 Node.js 22.13 或更高版本。

```bash
npm ci
npm run dev
```

开发服务器默认运行在 `http://localhost:5173/`。

## 验证

```bash
npm test
npx tsc --noEmit
npm run build
```

## 项目结构

- `app/`：页面和接口
- `components/`：练习界面与通用组件
- `lib/content/`：各年度双语题目数据
- `lib/content/lessons.ts`：学习路径、例题、基础练习与外部资料索引
- `lib/domain/`：学习记录、掌握度和筛选逻辑
- `public/questions/`：题目图形资源
- `tests/`：核心学习逻辑测试
- `workbench/`：从本地授权资料生成题图的辅助工具

本项目不是 Mathematical Association of America 的官方网站。题目页面保留来源说明；题目、翻译、解析和图形内容的再利用应遵守各自适用的授权范围。
